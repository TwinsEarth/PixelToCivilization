## 二、诊断

### 2.1 资源栏“数字被图标居中遮挡”——连续投诉（V9.4.2→V9.4.3→V9.4.4）

**证据链**：
- UITheme.CreateCanvas：CanvasScaler ScaleWithScreenSize / 1920×1080 / matchWidthOrHeight=0.6 → 布局宽随视口剧烈变化，1280~1920 视口下资源栏总宽 1961px 溢出。
- BuildTopBarV2：item 内 HorizontalLayoutGroup childControlWidth=false → icon/label 宽度不受布局组控制，内容溢出后图标与数字重叠/紧贴/错位。
- 用户截图（1302×141 像素逐列）：金色数字 50109 被绿色图标从中间劈成两段。

**根因**：bar 总宽 1961px 在 1280~1920 视口溢出 → item 压缩至 min 以下 → childControlWidth=false 使 icon/label 各自为政 → 图标盖住数字中段。

### 2.2 道路乱七八糟、一小段一小段

- ModernTrafficSystem.ManageRoads 每 Tick 按配额自动补建 + FindRoadExtension 邻接延伸 → 系统按数量配额自动铺路，不保证连续成网。
- IntercityNetworkSystem.RebuildEarth 自动铺城际公路/国际铁路/环岛环大陆公路。
- BridgeSystem.Tick/OnYear 自动扫描建桥（AutoBuildScan）。

### 2.3 车辆运动单调

- PickWander 每 3 秒随机换目标点，只有“巡航”一种行为。

## 三、求解（V9.4.4 裁决）

### 3.1 资源栏根治

BuildTopBarV2 布局原理变更：从“LayoutGroup 分配”改为“布局组强控子项宽度 + 内容留余”。

| 项 | V9.4.3 | V9.4.4 |
|---|---|---|
| item preferredWidth | 122 | 110 |
| item minWidth | 114 | 106 |
| item 内 childControlWidth | false | true |
| item 内 spacing | 4 | 2 |
| item 内 padding | (4,4,0,0) | (2,2,0,0) |
| icon | Icon(16)=32px | Icon(11)=22px |
| label preferredWidth | 76 | 78 |
| label minWidth | 无 | 1 |

新 bar 总宽 = 9×110 + 588 + 15×5 + 28 = 1681px：
- 1920×1080 布局宽 1920 → 余 239px 不溢出；
- 2K(2560×1440) → 余 1746px；
- 1280 视口仍溢出但 childControlWidth=true 保证同行等比压缩、图标恒左、数字完整。

### 3.2 道路/桥梁/铁路：禁止系统自动建造，改为玩家单点 + 自动联网

| 载体 | 关闭的自动逻辑 | 玩家入口 | 自动联网规则 |
|---|---|---|---|
| 道路 | ManageRoads/RefreshNow → 空操作 | 建造面板手动放置 | 新放置道路距最近既有道路 ≤40 格自动补同类型连接段并入路网 |
| 桥梁 | AutoBuildScan → 移除 | 建造面板“桥梁”项 → 点岸边 | 点岸边 + 最近可配对陆地，遵守跨距≤100、>50 跨海、普通 300 座/10 年、跨海 50 座/50 年、寿命衰减、两端陆地 |
| 铁路 | RebuildEarth 自动铺设 → 停 | 建造面板“铁路”项 → 点地图 | 点最近城市国家 + RailLinks 未铺邻国，最短跨海一线一列车；大陆内部 0 铁路 |

### 3.3 车辆/火车随机运动模式（真实时间轮换）

- 车辆 7 模式：0 巡航 / 1 来回跑 / 2 绕圈跑(半径20格) / 3 变速跑(0.5+0.5·sin(t)) / 4 堵车(×0.15) / 5 停车(180s恢复) / 6 跟车(保3格)。
- 每车真实时间 180 秒轮换（Time.unscaledTime 不受加速影响）；每 60 秒全地图重排队。
- 火车/地铁/高铁 CorridorMover.SpeedMul 每 180s 随机 0.6~1.4，60s 全图重随机。

## 五、闭合（生命周期）

1. 道路联网段：玩家放置 → ≤40 格 → 补连接段（PlaceBuilding 扣资源）→ 超距提示；连接段为建筑入存档。
2. 桥：玩家点岸边 → 校验配额/跨距/成本 → BuildBridge 写 S.BridgeRuns → DecaySweep 每年寿命结算照旧 → 读档 RebuildViews 重建；失败路径 AddEvent 提示原因。
3. 铁路：点地图 → 最近城市国家 → RailLinks 未铺邻国 → TrySeaRail → 一线一列车；失败提示；Rebuild 并入重建。
4. 车辆模式：ModeUntil 到期→重随机；全图 60s 重排队；停车 180s 自动恢复。
5. 并发：模式切换与 PickWander 共用目标字段，Mode 单值唯一。

## 七、验收标准

1. 资源栏 967/1280/1920/2K 四视口：图标恒在数字左侧同行、数字完整、不劈开不遮挡。
2. 玩家放置道路 → 40 格内自动联网成网；无自动铺路。
3. 玩家点桥梁 → 点岸边 → 最近对岸建桥；超跨距/超配额有提示；寿命衰减照常。
4. 玩家点铁路 → 点城市 → 跨海铁路一线一列车；大陆内部不放轨。
5. 车辆 3 分钟模式轮换、1 分钟全图重排队；火车变速。
6. 纯编译 error CS=0；WebGL 构建 BUILD_SUCCESS；浏览器 console 零异常。
