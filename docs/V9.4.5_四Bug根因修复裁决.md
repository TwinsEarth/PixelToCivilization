# V9.4.5 四 Bug 根因修复裁决

> 承接 V9.4.4（玩家单点建路/桥/铁路 + 资源栏根治）。本版四条均为用户实测 Bug，先定位根因再最小改动修复。
> 修改面：NavalSystem（敌船生成/敌舰 AI 速度与游弋）、BridgeSystem（玩家建桥 5 秒重试队列）、ModernTrafficSystem（道路联网 5 秒重试）、GameInputController（桥建筑分发）、UIManager（存档列表可见行数）、WebGLBuilder（版本串）。

## 1. 敌船生成：3 秒内等比例补齐（Bug 1）

### 现状（根因证据）
`NavalSystem.Tick` 生成块（NavalSystem.cs 433-446）：
```csharp
_spawnCd-=dt;
if (S.Era>=2 && hasWarship && _spawnCd<=0) {
    int headroom=MaxShips-S.Ships.Count-EnemyShips.Count;
    int target=Mathf.Min(S.Ships.Count,headroom);
    if (EnemyShips.Count<target && headroom>0) {
        _spawnCd=20f;
        if (Random.value<0.6f){ SpawnEnemyShip(); ... }   // ← 每20秒才60%概率补1艘
    }
}
```
- 补船周期 20 秒且带 60% 概率：我方有船时敌方长期为 0/极少——「我方很多船只&军舰，各方敌船并没有」直接坐实。
- 生成阵营 `RandomFaction()` 纯随机：可能连续刷同一阵营，其他阵营无船（「各方敌船并没有」）。

### 修复（确定性镜像 + 阵营均衡）
1. 检测条件不变（Era≥2 + 我方有军舰 + 全局 ≤200 上限），补船改为**确定性**：`_spawnCd=3f`（3 秒 1 艘）；`EnemyShips.Count<target` 时**无条件补 1 艘**（删除 60% 概率）。
2. **等比例分阵营**：新增 `LeastRepresentedFaction()`——统计 `EnemyShips` 各 `FactionId` 数量，取最少阵营（0 艘优先）；`SpawnEnemyShip` 改用该阵营，保证 3-5 个敌对阵营都有船且数量均衡。
3. 事件去重：仅在 `_pirateEngaged` 首次翻转时提示「敌方舰队出现」，补船过程静默（防刷屏）。

## 2. 高速公路/混凝土大桥/钢铁桁架桥：5 秒内自动连接&建造（Bug 2）

### 现状（根因证据）
- `BuildingDatabase` 已有 `bridge_wood/bridge_stone/bridge_steel/bridge_concrete`（Desc「自动连接相邻陆地」）与 `highway_modern`（高速公路）。
- `GameInputController.TryPlace` 只对 `type=="bridge"`（特殊基建卡）分发 `PlayerBuildBridge`；**`bridge_*` 四型走普通 `PlaceBuilding` 放置建筑块，从不触发建桥/联网**（Desc 承诺未实现）。
- `highway_modern` 走 `OnPlayerRoadPlaced` 即时联网，但**距离 >40 格直接放弃**，无后续重试；放置时机不当（潮汐/地图扩展中）即永久孤块。

### 修复
1. `TryPlace`：`type.StartsWith("bridge_")` → `PlaceBuilding` 成功后调用 `GM.Bridge.PlayerBuildBridge(p.x,p.z)`（点岸边→配对岸成真桥）。
2. `BridgeSystem` 新增 **5 秒重试队列** `_pendingBridge`：`PlayerBuildBridge` 失败（非「必须点在岸边」锚点错误）→ 入队；`Tick` 每 5 秒重试，成功即出队。
3. `ModernTrafficSystem` 新增 **5 秒重试队列** `_pendingRoad`：`OnPlayerRoadPlaced` 因 >40 格失败 → 入队，`Tick` 每 5 秒重试。

## 3. 敌舰雷达/追击/编队无效、停靠岸边（Bug 3）

### 现状（根因证据）
- **根因 A（无对象）**：Bug 1 生成逻辑 20s/60% 概率 → 敌舰长期为 0，雷达/追击自然无效。
- **根因 B（速度≈0）**：`UpdateEnemyShips` 三处移动均为 `e.X+dir.x*1.2f*dt`——每秒仅 1.2 世界单位，肉眼即「停靠岸边」；`SpeedOf(e)` 已存在却未用于敌舰。
- **根因 C（无目标即不动）**：敌舰无目标时 `else` 分支只有「40 格同伴共享目标」「100 格低血支援」，两者皆无则原地静止。

### 修复
1. 三处移动改为 `SpeedOf(e)*0.85f*30*dt`（敌舰略慢于我方、保留可追性）。
2. 无目标且无共享/支援时：新增 `CruiseEnemy(e,dt)`——外海随机选点巡航，到点换点。
3. 雷达/编队/支援逻辑保留（V9.4.3 已实现且正确），随 Bug 1+速度修复整体生效。

## 4. 存档列表增加到 5 行（Bug 4）

### 现状（根因证据）
- `UIManager.OpenSaveModal`：modal 888×640；`SaveSlotRow` 行高 58px；6 行（自动槽 0 + 手动 1-5）渲染后滚动区实际仅可见约 3-4 行，需滚动。

### 修复
- modal 高 640→780（`FitModal(380,520)→(380,620)`）；行高 58→46；6 行共 276px + 间距 ≈ 316px，滚动区默认可见 **6 行（≥5 行已保存）**，无需滚动。
