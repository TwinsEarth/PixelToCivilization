## 二、审计发现的核心风险

### 风险 R1（高）：作战系统运行时列表，新局重开无清理钩子 → 上一局实体残留
- **现象**：触发海军（敌舰/舰载机）或地面部队后再“重开新游戏”，上一局敌舰、舰载机、地面部队、编队、巡航、靠岸等运行时对象可能残留。
- **根因**：
  - 作战系统运行时列表不进 GameState（敌舰 `EnemyShips`、舰载机 `_strikes`、地面部队 `Ours/Enemies`、编队/巡航/靠岸字典均为系统私有）。
  - 全 Systems 中只有 MilitarySystem 有 `ResetForNewGame()`；NavalSystem、GroundWarfareSystem 均无新局清理钩子。
  - `GameState.Reset()` 只清“进存档的状态”，覆盖不到上述系统私有运行时列表。
- **判定**：上线阻断级问题（脏数据、幽灵单位、重复攻击、性能劣化）。

---

## 三、修复方案（最小杠杆，已写入代码）

1. **GroundWarfareSystem 新增 ResetForNewGame()**：销毁 Ours/Enemies 全部 View → 清空 → GroupCenter.Clear() → 清 _enemyFactions、_factionsInited=false、_enemySeen=false、Active=false → 复位 _spawnCd/_sepAt/_reformTimer。
2. **NavalSystem 新增 ResetForNewGame()**：销毁 EnemyShips 与 _strikes 全部 View → 清空 → 清 _patrol/_loadGoal/_dockWait/_formation → 清 _enemyFactions、_factionsInited=false、_pirateEngaged=false → 复位各计时器。
3. **GameManager.StartNewGame 接线**：State.Reset() 后依次调用 Military/Naval/Ground 的 ResetForNewGame()。
4. **版本号统一 9.4.7 → 9.5.0**：WebGLBuilder（BuildVer 驱动 verStamp 与 productVersion）、UIManager splash/底栏。其余 9.4.x 命中为历史特性标注，保留。
