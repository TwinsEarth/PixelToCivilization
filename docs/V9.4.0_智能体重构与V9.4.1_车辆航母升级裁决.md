## 0. 立界（项目基线）

### 结构不变量
- 时代-公历映射：游戏年 = 公历 + 3000；公元 1949 = 游戏年 4949 = Era 6（新中国）起始；Era 5 民国 4912~4949。
- 时代替换模式（V9.3.3 船只先例）：ModernEra => S.Year >= 4949；1949 前显示旧类型、1949 起直接替换为新类型，unlocked 恒真。
- 船只四级锚点造价：T1 木15 / T2 木100石30 / T3 木500石200金100 / T4 木3000石500铁200金1000。
- 航母既有挂载：Lv1 8 机 / Lv2 14 机 / Lv3 22 机。
- 九智能体共治：离线规则引擎永远在线=文明不灭绝硬保证；联网 DeepSeek 仅白名单增强、失败静默回退；密钥三级读取，源码零密钥。
- 现代交通装饰车：不进存档、无 Collider、只在道路上生成。

### 硬约束 / 冻结项
- LLM 动作白名单、SafetyNet 六条兜底（只增强不删减）、车辆必须只在路上、船只必须只在海里、包与仓库零 API Key。

## 2. V9.4.1 车辆时代升级与航母舰载机
