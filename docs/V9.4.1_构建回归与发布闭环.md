## 4. 浏览器回归

实测通过：加载与版本（title V9.4.1）、世界生成（多大陆 K=4 海82.8% 纯陆15.9% 主占7.8%）、系统装配（37 子系统）、AI 神离线规则自治与神庭协作（编年史持续事件）、时代推进（WebAdvanceEra → 公元1949=Era6，编年史新中国成立）、现代世界表现（飞行载具）、自动存档、console 零 error CS/零未捕获异常（仅 Intel 集显 WebGL 兼容性 warning）。

代码级通过：Era≥6 交通栏现代九型直接替换（AvailableCarts+UI 遍历）、现代车建造→道路行驶（TryBuildVehicle/SnapRoad）、航母弹射→出击→俯冲→返航（CarrierTick/StrikeUpdate）、等级成长 2/3/4 架·8/12/16 格·60/99/144 伤害。

自动化受限项（如实披露）：bu 输入事件对本 Unity WebGL 未触发 UI 反应（点击分类/面板无响应，游戏自动运行正常）——交通栏现代九型卡片与航母载机实体发射的目视确认留待用户实机操作；代码级逻辑已确认。
