## 二、逐项实现与验证

### 1. 存档系统完全重做（参考图：三格空存档槽）

- 自动存档槽 Slot0（每 5 分钟自动写档）+ 手动槽 Lv1–Lv5（每行 46 逻辑高：名称行 + 覆盖/读档/删除三按钮）。
- 快速存 / 快速读 / 刷新列表 / 导出 JSON / 导入 JSON / Debug 密码行。
- 面板 888×780 置顶显示，读档精确恢复世界 / 人物年龄 / 副本等全部持久字段。
- 验证：v953 纯编译 error CS=0；WebGL 构建 BUILD_SUCCESS；浏览器回归 console 零异常。

### 2. 高架桥地图 BUG 修复

- 现象：高架桥桥体导致实时扩展地图错乱、主地图闪烁。
- 根因：桥体实体在「每 100 年实时随机扩展」的重建流程中与地形网格/水位掩码交互异常。
- 修复：BridgeSystem.cs 610 行重写——桥体归属与地块掩码校验、扩展期桥体重挂、两桥端点必须均为陆地。
- 验证：构建通过；浏览器回归无桥体闪烁报错。

### 3. 建造新增「基建」标签栏

- BuildTabsV2 11 分类：基建标签插在军事与交通之间。
- TabOf 归位：bridge_wood / bridge_stone / bridge_steel / bridge_concrete（木石钢水泥桥）、viaduct_pier（高架桥柱）、railway_pre（铁路）、high_speed_rail（高铁）、airport（机场）等。
- WebOpenBuildTab 支持中英别名（浏览器 SendMessage 驱动）。
- 验证：构建通过；建造面板标签切换回归正常。

### 4. 军事栏补充地面作战部队

- 坦克 / 装甲车 / 导弹车：游戏年 ≥ 4949（公元 1949）解锁。
- SelectedBuildType = "ground:"+id；GroundWarfareSystem.cs 504 行实现地面装甲部队移动、索敌、开火，战斗规则参照军舰统一目录（V9.4.7 统一跨阵营作战）。
- 验证：构建通过；Debug 生成与交战路径在浏览器回归中验证。

### 5. 武器声光特效 + 统一粒子回收

- WeaponFxSystem.cs（263 行）：CannonFx 炮口闪光（自发光 Quad）+ 点光源 0.12s 骤衰 + 弹丸抛物 0.4s + 烟雾上升扩大淡出（约 1s）+ 即时音效（开火 / 爆炸）。
- 关键根因修复（假 null 崩溃）：旧实现把 ShaderHelper 全局共享缓存材质直接 Destroy，缓存后续返回被销毁的「假 null」，下一发 new Material(source) 抛 ArgumentNullException，表现为 C5/D3 每帧报错、火炮特效永久失效。
  - 修复：共享缓存材质绝不可 Destroy（置空引用即可）；各团烟雾是 new Material(base) 的私有实例，淡出结束后自行销毁——统一粒子生命周期与内存回收。
- 验证：构建通过；浏览器回归火炮特效持续生效、console 零异常。
