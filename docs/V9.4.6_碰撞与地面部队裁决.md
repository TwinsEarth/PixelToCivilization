## 1. 碰撞体系（六类）

| 对象 | 现状（根因） | 修复 | 数值（世界单位） |
|---|---|---|---|
| 船/军舰 | 移动逻辑无碰撞，编队成员可相互重叠（阵型间距 8 但无强制分离） | NavalSystem 我方+敌舰每帧两两分离（平方距离<分离半径² → 沿连线推开） | 分离半径 7.5（≈编队间距 94%，不破坏编队形态）；推开位移 0.4×dt；200+200 上限 O(n²)≈16 万/帧可承受 |
| 车 | ModernTrafficSystem 7 模式运动无碰撞，会重叠 | Car 间每帧分离 | 半径 3.0 |
| 鸟 | 编队阵型点间距仅 1.25–2.3，鸟 Lv2/Lv3 体积可重叠 | 阵型间距系数 ×1.6（I/Line 1.7→2.7、V 1.35→2.2 等）+ 个体间分离（含孤鸟） | 分离半径 1.8；500 上限 |
| 鱼 | 阵型点间距 0.9–1.4 | 阵型间距 ×1.4 + 个体分离（含孤鱼） | 分离半径 1.0；300 上限 |
| 人物 | 允许空间重叠 | **不改**（用户点名例外） | — |
| 植物/大树 | 生成 while 循环随机撒点，无"已种树间距"检查 → 大树可重叠 | 生成时近邻间距检查（稀疏哈希网格，格大小 12，查周围 3×3 格） | 普通树（BaseH<2.0）最小间距 2.4；大树/巨木（BaseH≥2.0）间距=两树半径和×0.85（≈3.6–4.6） |

**碰撞性能**：船 400+车 300+鸟 500+鱼 300 ≈ 1500 活动对象；分离用 `sqrMagnitude` 提前剔除 + 每 0.25 秒整批分离（非每帧），峰值 O(n²) 分摊到 4Hz。

### 规则（镜像 NavalSystem 战斗闭环）
- **时代门槛**：`Year>=1949`（ModernEra）解锁，军事栏直接替换/新增（非解锁制，参照 V9.3.3 军舰时代替换）。
- **生成/上限**：全局上限 60 辆（我方+敌方）；军事栏建造（资源：tank 钢120油40、apc 钢60油20、missile_vehicle 钢100油60）。
- **敌方镜像**：我方地面部队数 = 敌舰镜像规则——敌地面部队 3 秒内等比例补齐（LeastRepresentedFaction 复用），至少 3-5 阵营。
- **雷达/索敌**：发现 60 格（世界单位 60×Tile=240），射程内开火（Range×Tile），射程外追击（战斗航速+50%）。
- **编队**：3-7 辆一队（复用军舰 5 阵型：倒V/V/纵列/横排/半圆，间距 6 世界单位）。
- **巡航**：无目标时沿道路/陆地随机航点巡逻（半径 40-100）。
- **支援**：60 格内低血友车靠拢护航。
- **地面约束**：`terrain.IsWater(x,z)` 禁行（陆地部队不得下水）；出生/移动均找陆地。
- **生命周期**：运行时态不进存档；读档后 Tick 自愈（镜像补齐）。

## 4. 高架桥建造法（V9.4.6 需求⑧）

> 用户点名机制：高速公路&桥&铁路都有高架——玩家手动建柱子，高架桥自动无缝&连片布设。此前无专门实现（只有互通立交视觉与跨海桥桥墩），本版新增。

### 规则（BridgeSystem 新段）
| 项 | 值 |
|---|---|
| 解锁 | Era≥6（游戏年 4949 = 公元1949，新中国·现代工程） |
| 高架柱建筑 | `viaduct_pier`（Cat 基础/交通，Icon 🏗️，Era6，成本 钢80 混凝土40） |
| 放置 | 特殊基建面板「高架柱」→ 点地图任意格（陆地/浅水均可，跨海立柱） |
| 去重 | 距已有柱 < 4 世界单位视为同一柱位，不重复 |
| 自动连片 | 放置后找最近已建柱（≤60 跨距上限）→ `BuildViaduct` 生成高架桥面段 |
| 高架桥面 | 净空 ViaductDeckY=8、宽 6（双向车道+护栏+隔格桥墩钢柱）、tier=4 新档 |
| 通行 | 桥面格进 `S.BridgeCells`+`_cellTier=4`，`DeckHeightAt` 返回 8 → 车辆走高架 |
| 寿命 | 100~150 年随机（走 BridgeRuns 寿命衰减，到期拆除） |
| 重试 | 放置后未即时连片 → 5 秒静默重试队列（120 秒放弃），后续柱补齐后自动无缝连片 |
| 存档 | `S.Piers`（成对 x,z List<float>）进 SaveData（Snapshot/Apply），读档后 RebuildViews 重建柱+桥面 |
| 重开 | GameState.Reset 清 `Piers.Clear()`（防残留） |

### 生命周期
`玩家点柱 → 扣资源(钢80混凝土40) → S.Piers 记录+柱视觉 → 找最近柱(≤60) → BuildViaduct：BridgeCells 标桥面格+_cellTier=4 → BridgeRuns 追加(ax,az,bx,bz,tier=4,span,birth,life100~150) → DeckView tier4 高架桥面 → 车辆 DeckHeightAt=8 通行 → 寿命到期 DecaySweep 拆除 → 读档 RebuildViews 全量重建`。

### 验收
1. 1949（WebAdvanceEra）后特殊基建出现「高架柱」卡。
2. 连点 3 柱：首柱提示"再放相邻柱"，第二柱起自动连片（跨距≤60），地图出现高架桥面。
3. 车辆行至高架桥面格不落水（高度 8 通行）。
4. 存档/读档后柱与桥面完整恢复（RebuildViews）。
5. 寿命 100~150 年到期拆除（DecaySweep）。
