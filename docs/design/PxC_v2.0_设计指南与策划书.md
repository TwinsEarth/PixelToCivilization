## 卷首 · v2.0 总纲

### 0.1 一句话总纲

把"**一个 GameManager 巨型单例硬编码挂 50+ 系统**"彻底改造为"**一个极薄宿主（Host）+ 一切皆插件（Plugin）+ 能力授权（Capability）+ 数据块世界（Chunked SoA World）**"：

- **宿主**只保留让插件安全运行的最小内核（插件运行时、契约、事件总线、时间、数据容器、能力授权、存档/内存/崩溃框架），约占代码 20%；
- **其余一切**——经济、人口、建筑、科技、军事、海军、地面部队、交通、城市、文化、环境、扩张、智能体、内容副本——全部是**可独立开发、独立授权、独立测试、独立版本、独立发布**的插件；
- 插件之间**不直接互调**，只通过宿主的"**强类型事件总线 + 服务契约 + 能力授权**"通信，默认**最小权限、异常隔离、可随时插拔**。

### 0.2 v2.0 相对 v1.0 的六项关键升级

| # | 维度 | v1.0（v10.0.0/v10.1） | **v2.0** |
|---|---|---|---|
| 1 | 架构形态 | 分层 + 模块化（概念层） | **极薄宿主 + 一切皆插件**（含完整生命周期状态机与依赖拓扑） |
| 2 | 数据 | "展示层 SoA" + 模拟仍走 `List<class>` | **真 SoA 数据块世界**：模拟数据在连续内存，按 Chunk 组织、按块读写/存档 |
| 3 | 流式 | `SetActive` 按需休眠（常驻不释放） | **真加载/镜像卸载**：Addressables 引用计数，load/release 强制配对 |
| 4 | 权限 | 无权限模型 | **能力系统**：插件零默认能力，申请-授权-运行时校验，第三方加载前弹清单 |
| 5 | 内容 | 0 Prefab / 0 SO，全硬编码 | **配置化优先**：SO + Prefab 工作流，新增内容零代码 |
| 6 | 决策 | 13 项待裁决 | **全部裁决（见附录 A）**，直接开工，不再悬置 |

### 0.3 设计铁律（不可违背）

1. **先审计后改、信息不足先问、不编造**；无法真实运行/构建必须标注「未验证」，禁止假装成功。
2. **保持玩法兼容**：不随意换架构、不随意加依赖、不重写已成立的核心乐趣。
3. **完整文件交付**：不用"省略/同上/自行补充"。
4. **每个问题闭环**：现象 → 根因 → 修改文件 → 完整代码 → 验证命令/结果。
5. **数据与表现分离**：模拟是纯数据（可在无渲染下跑），视图只读数据并订阅事件。
6. **一切分配可审计**：对象池、Addressables 配对释放、GC 水位、卸载校验。
7. **塔不是楼**：形制类需求有可量化验收（多层收分）。
8. **密钥不进包/不进仓库**：API Key 仅游戏内输入或本地环境变量。

# 第一篇 · 产品定位与设计支柱

## 1.1 产品定位（一句话）

**一款以中华五千年为主轴、从远古到星际的开放世界 4X 文明模拟器；世界无限大、设备负担恒定、文明万年兴衰而不断绝；可单人游玩，也可团队/社区协作生产内容。**

- 主交付：**WebGL / HTML5**（IL2CPP → wasm，浏览器免安装即玩）；
- 兼容：Windows / macOS / iOS / Android（代码保留跨平台分支，非 WebGL 走高性预算档）；
- 品类：开放世界 + 4X + 文明模拟 + 塔防 + 智能体社会。

## 1.2 目标玩家与平台

| 维度 | 设定 |
|---|---|
| 核心玩家 | 喜欢文明/历史/模拟经营/宏大叙事的玩家；创作者（想自制副本、内容包） |
| 单局时长 | 短则几分钟（观察+命令），长则跨越万年（持续文明演进） |
| 输入 | 旧 Input Manager（鼠标点选 + 快捷键），保持现状不强制迁移 |
| 体验承诺 | 普通笔记本可跑：世界无限大，但**单位时间计算量与内存占用恒定** |

## 1.3 设计支柱（五条，贯穿全部决策）

| 支柱 | 含义 | 量化验收口径 |
|---|---|---|
| **P-1 真模拟** | 数据在连续内存，逻辑对数据批量运算（真 SoA/DOD） | 同帧可模拟实体数较 v9.9 提升 ≥ 10×；稳态 GC Alloc/帧趋近 0 |
| **P-2 真流式** | 世界分块、按需加载、镜像卸载 | 运行 1000 游戏年后，内存峰值较开局增幅 < 20% |
| **P-3 配置化** | 数值/内容在 SO、Prefab，不改代码可调 | 新增 1 种建筑/单位不写任何 .cs（仅资产） |
| **P-4 模块化** | 系统解耦、事件总线、程序集边界清晰 | 单个系统可独立增删，主循环无回归；插件可热插拔 |
| **P-5 表现力** | 统一美术风格、历史考据、塔≠楼、特效 LOD | 五类塔防通过"形制验收"；特效按需加载且统一回收 |

# 第二篇 · 核心玩法设计

## 2.1 核心循环（三层）

**瞬时循环（秒级）**：观察局势 → 下达建设/军事/研究命令 → 看数值与事件反馈。

**单局循环（百年级）**：探索（地图/海图/星图）→ 扩张（聚落/殖民/领土）→ 开发（经济/人口/科技/奇观）→ 征服（战争/外交/统一）→ 朝代兴衰循环。

**长期循环（万年级）**：远古 → 王朝循环（恢复/繁荣/过剩/崩溃，约 300 年节拍）→ 工业化 → 海洋/太空 → 星际。智能体议会（九神 SafetyNet）保证"**允许倒退、不允许灭绝**"。

## 2.2 4X 设计

| X | 内容 | 关键插件 |
|---|---|---|
| eXplore 探索 | 多大陆随机/真实地球、海图、星图、探险副本 | `pxc.expedition`、`pxc.mapgen`、`pxc.colonization` |
| eXpand 扩张 | 聚落、领土、殖民、地图自然延展、势力 | `pxc.nation`、`pxc.colonization`、`pxc.expand.world` |
| eXploit 开发 | 15 资源、经济、人口、科技、城市、奇观 | `pxc.economy`、`pxc.population`、`pxc.tech`、`pxc.wonder` |
| eXterminate 征服 | 陆/海/空三军、塔防、集结、统一 | `pxc.military`、`pxc.naval`、`pxc.groundforce`、`pxc.combat`、`pxc.rally` |

## 2.3 文明模拟核心（中华五千年重点）

### 2.3.1 时间步进
- 开局：**公元 1700 年（清康熙）**，游戏年 = 公元年 + 3000 = **4700**；大航海已开、海洋已解锁。
- 推进：`Day += dt × DaySeconds`（DaySeconds = 365/60），满 365 进 1 年；游戏年连续递增、**不跳年**。
- **自适应分段**（保留并强化）：高倍速/掉帧时一次跨年多个，每做完一个年结检查现实耗时是否超预算（WebGL 6ms / 桌面 10ms），超了剩余 Day 结转下帧；`HardCapTicks=120` 兜底；EWMA 记录单年结平均耗时。
- 朝代/时代由游戏年换算（`DynastyDatabase.GetIndexByYear / GetEraByYear`）；开局 `SnapToStartYear` 静默对齐。
- 速度档：普通最高 100×、Debug1 最高 300×、Debug2（密码 `ToFuture`）最高 1000×。
- 加速冷冻：加速累计满 100 游戏年 → 冷冻 300 现实秒，期间倍速封顶 10（防滥用）。

### 2.3.2 朝代更替
- 朝代/时代由年份换算（已成立）；换朝触发"**人口周期重置、地广人稀、民心回升**"。
- 引入吏治腐败度 `Corruption`、明君/昏君、朝代士气 `DynastyMorale` 参与王朝周期：
  - 新朝：低腐败、高民心、土地重新分配（人口/资源压力释放）；
  - 盛世：人口增长、经济繁荣；
  - 后期：腐败上升、土地兼并、人口逼近承载力；
  - 崩溃：战乱/灾害导致人口锐减，随后新朝循环。

### 2.3.3 人口 / 经济 / 资源聚合
- **人口是聚合统计**（出生/死亡是数字），个体人形为视觉抽样。v2.0 把聚合统计建立在**真 SoA** 上：按势力/年龄/职业分层的连续数组，而非单个 int。
- **资源 15 种，统一 `double`**（已治本，保留）；经济产出/消耗按年批量结算，禁止再用 float。
- 资源系统口径：`Dictionary<string,double>` 逐步迁移为按资源 id 索引的 double 数组（去 GC、可批量）。

### 2.3.4 数值溢出（强制上限钳制）
- 所有"增长类"曲线必须有**上限**：承载力（人口）、市场饱和（经济）、现代低生育率（人口转型）、资源上限（double 钳制）。
- 关键累积器用 `double` 并做范围校验；`int` 仅用于计数/索引，跨数量级计数用 `long`/`double`。
- 必须补：人口/军事/经济长期增长的上限钳制与溢出审计（防 int 溢出、防指数增长爆表）。
- 验收：Debug 跳年至游戏年 13000（公元 10000）无 NaN/Inf/负资源、无数量级爆表。

### 2.3.5 历史数据配置化
- 朝代年表、时代阈值、历史事件、政策、科技、奇观全部迁移到 **ScriptableObject**（见第四篇 §4.5 与开发计划）。
- 运行时数据库只读加载 SO；新增/修改历史不改代码。

### 2.3.6 大地图 / 长跨度性能
- 世界分块（Chunk），只模拟/渲染**活跃块**（玩家附近 + 关键事件）；其余统计层推进或休眠。
- 复杂度从 O(世界大小) 变为 **O(活跃视野/活跃块)**。
- 智能体按 AI LOD 分层（统计/简化/完整），与记忆共享耦合，切换不丢世界状态。

# 第三篇 · 系统设计（军事/指挥/交通/城市/智能体）

> 每个系统遵循统一规格：`职责 | 输入数据 | 输出事件 | 生命周期 | 数值口径 | 边界 | 验收`。

## 3.1 军事与指挥（历史重灾区，最高优先）

### 3.1.1 集结令（Rally）—— 幂等 + 限频 + 命令队列（**根治**）

- 形制：蓝旗=海军 / 绿旗=地面 / 红旗=军人；100 格内列阵；>100 格走运输机/直升机。
- 历史 Bug：连续插旗 5–10 次必崩（`null function or function signature mismatch`）。
- **v2.0 设计（强制）**：
  1. 插旗操作**幂等 + 限频 + 命令队列**：同一时刻只处理一个集结命令，新命令先入队；
  2. 每次插旗/重插前**先清理上一次未完成命令与临时视图**（旗、标记、投射物），避免句柄/内存累积；
  3. 集结目标无效（水域/不可达/空）要**安全失败**并提示，绝不抛异常；
  4. 所有插旗产生的临时对象走对象池，命令用结构体缓冲（零 GC）。
- **验收（硬指标）**：连续插旗 **50 次**无崩溃、无内存增长（Memory Profiler Diff 归零）、无句柄泄漏；部队真实移动到旗帜周围列阵；>100 格正确触发空运。

### 3.1.2 地面作战部队（GroundForce）—— 分类表 + 自主 AI（**根治**）

- 1949 前：**骑兵 / 阵兵（3 人组）/ 战车**；1949 后：**坦克 / 装甲车 / 导弹车**。
- 历史 Bug：生成后被拉到大陆湖中、不主动寻敌/组队/战斗（疑似误把骑兵当民船牵引）。
- **v2.0 设计（强制）**：
  1. **实体分类表**（单一权威）：骑兵/阵兵/战车 = **陆地类（Land）**，禁止进入船只牵引/水流/锚点漂流逻辑；
  2. 生成点 = 出生地（兵营/集结点），**严禁生成后被任何"回港/回流"系统拉走**；
  3. AI 自主行为链：**寻敌 → 组队 → 布阵 → 攻击 → 追击 → 回撤**（状态机），可点选、可查看属性、可手动/战斗中升级；
  4. 全 **10 维参数**（速度、耐久、攻击、防御、射程、射速、载人量、体积、军衔、智能等级）随等级成长；
  5. 速度口径：地面部队 **0.01–0.1**（世界单位/秒，经缩放），严格按等级与代差。
- **验收（硬指标）**：骑兵生成即在陆地、永不掉湖；可点选/升级；自主接近并攻击敌方；1949 后坦克/装甲车/导弹车速度显示与实际一致。

### 3.1.3 海军（Naval）
- 1949 前木船 / 之后轮船~航母、潜艇、舰载机；上限 200，敌方镜像生成。
- 攻击半径：**海军最高 ≤100 格、地面 ≤50 格**。
- 航母舰载机自动起降；潜艇下潜/上浮；编队/巡航/战斗增益。
- 民用船（小船/帆船/渔船）巡游锚点逻辑**只对船舶类生效**，严禁误用于陆地实体。

### 3.1.4 统一战斗（Combat）
- 统一结算陆/海/空/塔防的伤害、命中、射程、射速、经验；投射物统一由对象池管理。
- 经验/等级：战斗中击杀/助攻累积经验，达到阈值自动升级并刷新 10 维参数。

## 3.2 塔防五型（形制 = 硬性验收，塔≠楼）

- **统一形制**：多层收分塔，**3–4 层，每层比下一层小约 18%（参照树木分层），层间出檐**；禁止做成方形高楼。
- 验收可量化：层数 ∈ [3,4]；相邻层底边尺寸比 ≈ 0.82；高度不超过底边宽度的设定倍数（低矮、敦实）。

| 塔 | 形制（多层收分） | 攻击 / 发射 / 爆炸特效 |
|---|---|---|
| **箭塔** | 木制结构，顶部弩箭造型，多层收分 | 真实**箭矢**逐支射出（对象池回收），命中有羽毛/木屑反馈 |
| **火塔** | 土垒尖塔，多层收分 | 喷**火龙**一烧一片（锥形/带状），落地继续燃烧 **1s**（地面火焰贴地） |
| **炮塔** | **方形低矮基座 + 上置旋转炮塔**（非高楼，随时调角） | 一颗颗**炮弹**射出，命中产生**不同尺寸蘑菇云**（黑泡缩小到 1/3） |
| **碉堡** | 圆形堡垒（非塔），四面机枪 | **四面八方**子弹射出（多点同时开火） |
| **烽火台** | 几块大木上架一口大锅 | 示警烟火（烟柱 + 火星） |

- 所有投射物、火焰、烟雾、光线、粒子**按需加载、统一回收**，受 FrameBudget/算力分层控制；远景自动降密度/关闭。
- 特效真实存在且可在浏览器目视（历史上多次"特效没做"，必须构建后截图验证）。

## 3.3 交通 / 城市

- **车辆不再强制走道路**（已规定，保留）；禁止系统在大陆内部自动建道路/铁路，**只能玩家手动**。
- 五代铁路机车：蒸汽 / 内燃 / 电力 / 高铁 / 磁悬浮；高架桥、城际网络、桥梁。
- 城市三系统：公共设施、城市指标（就业/人口）、城市财政（税率/地价/等级）。
- 登乘（Embark）：人员上车/上船由统一登乘规则处理；登乘实体停止陆地移动、视图隐藏。
- 验收：车/火车可自由移动（不被拉回道路）；路桥仅玩家手动创建；高架桥不错位。

## 3.4 智能体（AgentDirector）—— 身份真驱动

- 现状：118 身份 / 42 子系统，每物体/系统持简介，三模式（离线/在线/混合）。
- v2.0 升级：让身份层从"自我介绍 + 委托系统"升级为**真正驱动行为决策**：
  **身份（Identity）→ 职责目标（Goals）→ 行为（Behaviors）→ 命令（Commands）→ 经总线执行**，与 SoA 模拟联动。
- 全量身份覆盖（每个实体/系统都有身份与职责）：
  树木、建筑、鱼、鸟、人、车、船、桥、火车、天气、时间、内存/算力管理、存档管理、语音广播、指挥官、土地、海洋、道路、岛屿、地图生成、科技、副本等。
- 典型职责示例：
  - 航空母舰：负责我方海域的安全/防御/攻击/侦查/支援/巡航；
  - 坦克指挥官：负责我方陆地作战的安全/防御/攻击/侦查/支援/巡航；
  - 消防/洒水/清扫/救护：缺水/道路/险情/伤员时自主前往救援；
  - 天气（小天）：负责雨/雪/风的时令；时间（小时）：负责时间记录与历史事件。
- 三模式：
  1. **离线模式**：本地行为库（Skill/规则/效用）自主决策；
  2. **在线大模型模式**：联网调用大模型决策；
  3. **混合模式**：在线操作累积并生成新的本地 Skill，存入本地离线行为库；联网时上传豆包云盘，下次版本更新重新打包，成为公用离线行为库（离线越用越强）。

# 第四篇 · 美术与表现力

## 4.1 风格定位
- **主风格：低多边形（Low-Poly）+ 轻度程序化/积木感 + 历史考据**；干净、明快、清晰。
- 统一三种来源（CC0 模型、乐高积木、程序化方块）到同一套几何语言：低面数、清晰色块、硬边/平面着色（可选 flat shading）。
- 远景不再是"自动方块"，改为美术提供的简化模型（authored LOD）。

## 4.2 建筑 / 塔防形制规范
- **塔≠楼**：塔 = 多层收分（3–4 层，每层 −18%，出檐）；楼 = 多层等宽建筑。塔防五型一律走塔形制。
- 按年代/功能/材质差异化：木结构（箭塔/烽火台）、土垒（火塔）、石/砖（炮塔/碉堡）。
- 每类建筑有：形制、材质、色彩、LOD 三档、攻击特效。

## 4.3 色彩规范
- 自然色：地形（土/绿/沙）、海洋（蓝青）、植被（多档绿）；
- 材质色：木（暖棕）、土（赭黄）、砖石（灰/赭）、金属（钢灰）；
- 强调色（阵营/九神/军情）高饱和但克制；UI 强调色与游戏内阵营色一致。

## 4.4 特效规范
- 箭矢/炮弹/子弹 = 实体投射物（对象池）；
- 火 = 火龙 + 落地持续燃烧 1s；爆炸 = 多尺寸蘑菇云（缩小 1/3）；
- 所有粒子/光/烟按需加载、统一回收，受 FrameBudget/算力分层控制；远景降密度/关闭。

## 4.5 UI 规范
- 从"全代码 UI"逐步过渡到"**UI Prefab + 主题 SO**"（UITheme 资产化）；
- 统一字体、字号阶梯、配色、间距、图标；
- 已知形制：AI 密钥框缩小、字号 20、按钮框与文字等高；
- **UI 变更必须在真实构建里目视验收**（用户多次批评点），并截图留证。

# 第五篇 · 技术架构（内存/崩溃/存档/流式/LOD/算力）

> 插件化总览、宿主组成、契约完整定义见《PxC_v2.0_插件化架构开发计划》。本篇给口径与验收。

## 5.1 内存架构（真分配可审计）

### 5.1.1 统一对象池（PoolManager）
- 覆盖：频繁创建/销毁的 GameObject、UI 元素、投射物、特效、事件对象、模拟数据对象。
- 纯数据对象池（命令/事件/模拟数据）：避免逻辑层 new class；高频命令/事件用结构体缓冲（零 GC）。
- 统一 API：Rent/Return/Warmup/ShrinkIdle/ClearAll/Stats；按 key 分桶、容量与自动缩容。

### 5.1.2 Addressables 真流式（强制镜像配对）
- 安装 `com.unity.addressables`，把 Resources 内容迁移为 Addressable 分组（按 Chunk/时代/类型分包）。
- **铁律**：每次 `LoadAssetAsync` 保留 `AsyncOperationHandle`，用完 `Addressables.Release(handle)`；**load/release 镜像配对**，禁止只 Destroy 不 Release。
- 引用计数由 Addressables 管理；加载/卸载在业务代码中成对出现，静态扫描 + 运行时 LiveCount 双重校验。

### 5.1.3 内存预算与监控
- 三级水位：**1.1GB High / 1.5GB Critical**；Critical 时 GlobalSpawnGate 关闭。
- 安装 `com.unity.memoryprofiler`；在关键节点（场景切换、回合结束、读档后）自动快照并 Diff，检测泄漏。
- 验证口径：GC Alloc/帧、托管堆、原生内存、Mesh/Texture 占用、池租借/空闲、Addressables LiveCount。

### 5.1.4 真数据导向（DOD）
- 模拟数据 = 连续内存纯数据结构（SoA），按 Chunk 组织；逻辑批量遍历数组（Burst 友好），不产生逐实体 GameObject。
- **路线裁决：自研轻量 SoA**（依赖少、风险低、兼容好）；不上 Entities/DOTS（见附录 A）。

## 5.2 崩溃架构（分层 + 恢复）

- **全局捕获三路**：
  - `Application.logMessageReceived`（所有日志/异常）；
  - `AppDomain.CurrentDomain.UnhandledException`（未处理异常）；
  - `TaskScheduler.UnobservedTaskException`（异步任务异常）。
- **分层处置（LayeredGuard）**：P0 → 安全模式；P1 → 连 5 次升级安全模式；P2 → 吞掉并计数。
- **本地崩溃快照**：时间戳、场景名、当前回合/年份、最近 N 条日志、堆栈；崩溃时自动保存最近游戏状态。
- **启动恢复**：检测上次异常退出 → 提供"恢复上次进度"；回滚槽（3 个）兜底。
- Crashlytics/Firebase：**v2.0 暂不引入**（预留上报接口），先用本地崩溃报告（见附录 A）。

## 5.3 存档架构（DTO + 迁移 + 原子写 + 分块）

- DTO 模式：存档数据与运行时数据分离；**`int version` 字段** + MigrationManager 逐版本迁移；禁 BinaryFormatter。
- 序列化：JSON（JsonUtility；新增复杂结构时再评估 Newtonsoft），人类可读、便于调试。
- **原子写**：先写 `.tmp` → rename 正式文件；保留 `.bak`，失败回滚；FNV-1a 校验（`.cksum`）。
- 槽位：5 手动 + 3 回滚；异步写入、入口集中化、dirty flag 触发（仅变更才存）。
- WebGL：IndexedDB 正文 + PlayerPrefs 摘要（双写）。
- **分块存档**：大规模模拟数据按 Chunk 存储，只存脏块；可选压缩。
- 兼容：旧档必须能在新版本加载并自动迁移（每插件注册自己的存档段与迁移器）。

## 5.4 LOD（五维）

| 维度 | 内容 |
|---|---|
| 几何 LOD | LODGroup 3 档（完全/简化/像素）；authored 简化模型取代自动方块 |
| 纹理 LOD | Mipmap；按需流式纹理块 |
| 物理 LOD | 近处完整刚体，远处简化碰撞体/统计 |
| AI LOD | 统计 / 简化决策 / 完整决策 三档（按距离+事件） |
| 记忆 LOD | 近期高精度，远期摘要/重要性衰减 |

- 切换用淡入淡出防跳变；**LOD 切换不改变世界状态**（与记忆共享耦合）。

## 5.5 算力优先级

- **P0Core 永不节流**；P1Tactical 1Hz（Low 档 2s）；P2Ambient 按 AmbientHz（4/2/1Hz），高负载跳过。
- 探针：`[Layered] p0fatal / p1recover / p2swallow / p2skip / ambientHz / frameMs`。
- 帧预算：WebGL 6ms / 桌面 10ms；画质自适应 High/Mid/Low，动态调阴影距离、粒子、名额。
