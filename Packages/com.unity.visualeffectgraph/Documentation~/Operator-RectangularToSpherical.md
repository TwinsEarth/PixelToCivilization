# Rectangular to Spherical

菜单路径： **Operator > Math > Coordinates**

运算符**Rectangular to Spherical**执行矩形XYZ空间到球形（θ/φ/距离）空间之间的3D坐标转换。

## 运算符属性

| **Input**      | **Type** | **描述**|
| -------------- | -------- | ------------------------ |
| **Coordinate** | Vector3  |输入三维坐标。|

| **Output**   | **Type** | **描述**|
| ------------ | -------- | ------------------------------------ |
| **theta**    | float    | Theta球面角度（以弧度为单位）。|
| **phi**      | phy      | Phi 球角度（以弧度为单位）。|
| **distance** | float    |到原点的输出距离。|
