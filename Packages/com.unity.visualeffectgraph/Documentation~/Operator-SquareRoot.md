# Square Root

菜单路径： **Operator > Math > Arithmetic > Square Root**

 **Square Root**运算符计算每个输入值的Square Root。例如，输入（0.25，1，9）输出（0.5，1，3）。负数的Square Root未定义。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。**Square Root**运算符始终返回与其输入类型相同的值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| 操作符评估的价值。 |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |输入的Square Root。 <br/>**类型**更改以匹配的**X**类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。使用下拉列表选择**X**端口类型。有关此属性支持的类型的列表，请参见[可用类型](#available-types)。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
