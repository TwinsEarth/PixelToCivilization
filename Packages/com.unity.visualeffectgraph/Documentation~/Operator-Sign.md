# Sign

菜单路径： **Operator > Math > Arithmetic > Sign**

 **Sign**运算符计算输入的Sign并返回输入是正、负还是0：

- 如果**X**大于0，则结果为1。
- 如果**X**小于0，则结果为 - 1。
- 如果**X**为0，则结果为0。

例如，输入（0.3，0.4， - 5）输出（1，1， - 1）。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。此运算符始终返回与其输入类型相同的值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |从1中减去的输入值。的类型相匹配的 **X****类型**更改。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。使用下拉列表选择**X**端口的类型。有关此属性支持的类型的列表，请参见[可用类型](#available-types)。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **int**
-  **uint**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
