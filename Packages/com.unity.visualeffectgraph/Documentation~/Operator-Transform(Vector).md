# Transform (Vector)

菜单路径： **Operator > Math > Geometry > Transform (Vector)**

 **Transform (Vector)** 操作符将变换应用于矢量，以对其进行偏移、旋转或缩放。

## 运算符属性

| **Input**     | **Type**  | **描述**|
| ------------- | --------- | -------------------------------------------------- |
| **Transform** | Transform |此运算符的变换应用于向量。|
| **Vector**    | Vector    |此运算符变换的向量。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ----------------------- |
| **vec**    | Vector   |转换后的向量。|
