# Floor

菜单路径： **Operator > Math > Clamp > Floor**

 **Floor**运算符将输入值向下舍入为最接近的整数。例如，（4.1，4，4.8）的输入输出（4，4，4）。

此操作符接受各种类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |输入的下限值。 <br/>**类型**更改以匹配的**X**类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。你可以从所有[可用类型](#available-types)类型中选择一种类型。

### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
