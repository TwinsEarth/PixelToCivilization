# AppendVector

菜单路径： **Operator > Math > Vector**

按顺序 **附加向量**[级联运算符](Operators.md#cascaded-operators)追加所有输入，并将其输出到最大长度为4的单个向量中。如果输入包括四个以上的值，则此运算符将丢弃更多的值。例如，如果输入是向量3和向量2，则输出是包括来自向量3的三个值和来自向量2的第一个值的向量4。

## 运算符属性

| **投入**| **Type**                                | **Description**                                  |
| ---------------------------------------------------------- | --------------------------------------- | ---------------------------------------------- |
| [可配置](#operator-configuration)- **A**默认情况下| [Configurable](#operator-configuration) | An input value to append to the output Vector. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Output** | Dependent |与输入一起打包的向量。 <br/>**类型**更改以匹配输入所包含的值的数量。这可以是浮点数、向量2、向量3或向量4。|

## 运算符配置

要查看此[级联运算符](Operators.md#cascaded-operators)配置，请单击**齿轮**节点标题中的图标。

在这里，你可以更改每个输入的名称以及每个输入值的类型。

### 可用类型

你可以将以下类型用于**输入值**和端口：

-  **位置**
-  **向量**
-  **方向**
-  **矢量3**
-  **矢量2**
-  **漂浮**
