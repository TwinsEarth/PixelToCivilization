# Volume (Torus)

菜单路径： **Operator > Math > Geometry > Volume (Torus)**

 **Volume (Torus)** 运算符计算环面的体积。这等于，**2 π<sup>2</sup> R r<sup>2</sup>**其中**R**是长半径，**R**是短半径。

## 运算符属性

| **Input** | **Type** | **描述**|
| --------- | -------- | ------------------------------------------------- |
| **Torus** | Torus    |此运算符计算环面的体积。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------ |
| **Volume** | float    |环面的体积。|
