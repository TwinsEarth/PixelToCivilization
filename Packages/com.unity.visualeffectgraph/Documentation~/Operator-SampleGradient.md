# Sample Gradient

菜单路径： **Operator > Sampling > Sample Gradient**

 **Sample Gradient**操作符在0和1之间的指定时间对梯度进行采样。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------------------------ |
| **Gradient** | Gradient |此运算符采样的梯度。|
| **Time**     | float    |此运算符用于对梯度进行采样的时间。此值被限制在0和1之间。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------ |
| **s**      | Vector4  |梯度的采样值。|
