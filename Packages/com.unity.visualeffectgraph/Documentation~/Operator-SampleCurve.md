# Sample Curve

菜单路径： **Operator > Sampling > Sample Curve**

 **Sample Curve**运算符在指定时间对曲线进行采样。在对曲线进行采样时，它会考虑输入曲线的左右重复模式。

## 运算符属性

| **Input** | **Type** | **描述**|
| --------- | -------- | ------------------------------------------------ |
| **Curve** | Curve    |此运算符从其中采样的曲线。|
| **Time**  | float    |此运算符用于对曲线进行采样的时间。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | --------------------------------------- |
| **s**      | float    |输入曲线的采样值。|

## 局限性

当Unity在GPU上评估此操作符时，它不会考虑乒乓模式。在这种情况下，采样模式默认为箝位。
