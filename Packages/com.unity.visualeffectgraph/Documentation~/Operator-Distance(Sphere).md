# Distance (Sphere)

菜单路径： **Operator > Math > Geometry > Distance (Sphere)**

 **Distance (Sphere)**操作符取一个球体和一个位置，并计算：

- 球体上距离该位置最近的点。
- 最近点与位置之间的距离。

此操作符不支持具有不同长度缩放轴的球体（椭球体）。如果使用椭球体作为输入，则此操作符使用其最长轴来定义球体。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------------------------ |
| **Sphere**   | Sphere   |此运算符计算的球体。此运算符返回的点（**最接近位置**）是此球体**位置**上最接近的点。|
| **Position** | Position |此运算符评估的位置。此运算符返回的点（**最接近位置**）是距离此位置最近的点**球体**。|

| **Output**          | **Type** | **描述**|
| ------------------- | -------- | ------------------------------------------------------------ |
| **closestPosition** | Position |上 **球体****位置**的最近点的位置。|
| **distance**        | float    |从**位置**到**最接近位置**的距离。如果**位置**在外部**球体**，则此值为正。如果**位置**在内部**球体**，则此值为负。|
