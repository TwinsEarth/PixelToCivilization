# Distance (Line)

菜单路径： **Operator > Math > Geometry > Distance (Line)**

运算符**Distance (Line)**取一条线和一个位置，并计算：

* 直线上距离位置最近的点。
* 最近点与位置之间的距离。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------------------------ |
| **Line**     | Line     |此运算符计算的行。此运算符返回的点（**最接近位置**）是这条线**位置**上最接近的点。|
| **Position** | Position |此运算符评估的位置。此运算符返回的点（**最接近位置**）是距离此位置最近的点**线**。|

| **Output**          | **Type** | **描述**|
| ------------------- | -------- | ------------------------------------------------------------ |
| **closestPosition** | Position |上 **线****位置**的最近点的位置。|
| **distance**        | float    |从**位置**到**最接近位置**的距离。|
