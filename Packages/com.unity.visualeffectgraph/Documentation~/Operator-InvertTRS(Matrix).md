# InvertTRS (Matrix)

菜单路径： **Operator > Math > Geometry > InvertTRS (Matrix)**

 **InvertTRS (Matrix)** 运算符对TRS（平移、旋转和缩放）矩阵求逆。

一个矩阵是另一个矩阵的InvertTRS (Matrix)，当你把它们相乘时，结果是[单位矩阵](https://docs.unity3d.com/ScriptReference/Matrix4x4-identity.html)。有关InvertTRS (Matrix)的详细信息，请参见[矩阵4x4.InvertTRS (Matrix)](https://docs.unity3d.com/ScriptReference/Matrix4x4-inverse.html)。

## 运算符属性

| **Input**  | **Type**  | **描述**|
| ---------- | --------- | --------------------------------- |
| **Matrix** | Matrix4x4 |这个算子求逆的矩阵。|

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ---------------------------------- |
| **o**      | Matrix4x4 |矩阵求逆的结果。|
