# ArcSphere

由角度和  [Sphere](Type-Sphere.md) 定义的球体的实心弧体。如果您只想使用球体的一部分，例如半球，这将非常有用。

## 属性

| **属性** | **描述**                                        |
| ------------ | ------------------------------------------------------ |
| **Sphere**   | 要取其一部分的 [Sphere](Type-Sphere.md) 。|
| **Arc**      | 球体段的角度（以弧度为单位）。         |
