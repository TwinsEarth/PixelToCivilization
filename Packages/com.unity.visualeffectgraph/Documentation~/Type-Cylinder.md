# Cylinder

由位置、高度和半径定义的 3D 圆柱体。

## 属性

| **属性**    | **描述**                                              |
| --------------- | ------------------------------------------------------------ |
| **Center**   | 圆柱体的位置。 |
| **Radius** | 圆柱体的半径。                        |        |
| **Height**      | 圆柱体的高度。                                      |
