# Modulo

菜单路径： **Operator > Math > Arithmetic > Modulo**

 **Modulo**运算符将第一个输入除以第二个输入并计算余数。例如，输入4.5%1.5输出0，输入8%3输出2，输入（4，8，4) % (2，3，3）输出（0，2，1）。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。第一和第二输入总是相同类型的。

## 运算符属性

| **Input** | **Type**                                | **描述**|
| --------- | --------------------------------------- | ------------------------------------------------------------ |
| **A**     | [Configurable](#operator-configuration) |红利。运算符将此值除以**乙**并返回余数。|
| **B**     | [Configurable](#operator-configuration) |除数。运算符除**A**以此值并返回余数。|

| **Output** | **Type**    | **描述**|
| ---------- | ----------- | --------------------- |
| **Out**    | Output port |A乘以B的Modulo。|

## 运算符配置

要查看**Modulo**运算符的配置，请单击**齿轮**运算符标题中的图标。你可以在所有[可用类型](#available-types)类型中选择一种。



### 可用类型

你可以为**输入**端口使用以下类型：
-  **float**
-  **int**
-  **uint**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
