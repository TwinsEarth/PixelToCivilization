# Frame Index

菜单路径：**Operator > BuiltIn > Frame Index**

**Frame Index** 操作员输出内部视觉效果管理器帧索引。这相当于 [Time.frameCount](https://docs.unity3d.com/ScriptReference/Time-frameCount.html)。VFX Graph 在内部使用此值来检查运动矢量的有效性。

## 运算符属性

| **输出** | **类型** | **描述** |
| --- | --- | --- |
| **frameIndex** | uint | 当前帧索引。 |
