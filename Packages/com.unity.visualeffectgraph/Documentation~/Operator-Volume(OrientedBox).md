# Volume (Oriented Box)

菜单路径： **Operator > Math > Geometry > Volume (Oriented Box)**

 **Volume (Oriented Box)**操作员计算定向框的体积。这等于，**X Y Z**其中**X**是宽度，**是的**是高度，**Z**是盒子的长度。

## 运算符属性

| **Input** | **Type** | **描述**|
| --------- | -------- | -------------------------------------------------------- |
| **Box**   | Box      |此运算符计算的体积的定向框。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------- |
| **volume** | Float    |定向框的体积。|
