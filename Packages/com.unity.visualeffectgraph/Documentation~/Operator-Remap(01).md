# 重新映射 [- 1..1] => [0..1]

菜单路径： **Operator > Math > Remap > Remap**

 **重新映射 [- 1..1] => [0..1]**运算符将输入值从范围 - 1到1线性重新映射到范围0到1. 这相当于运算（x *0.5) + 0.5.例如，输入 - 1将计算（ - 1*0.5) +0.5，并输出0。

此操作符接受各种类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。

## 运算符设置

| **Setting** | **Type** | **描述**|
| ----------- | -------- | ------------------------------------------------------------ |
| **Clamp**   | bool     |在运算符重新映射之前，将**投入**钳制到输入范围。|

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| Input     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| Output     | Dependent |重新映射的值 <br/>**类型**。更改以匹配**投入**类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。

| **Property** | **描述**|
| ------------ | ------------------------------------------------------------ |
| **Type**     | **投入**端口和输出值的值类型。有关此属性支持的类型的列表，请参见[可用类型](#available-types)。|

### 可用类型

你可以将以下类型用于**输入值**和端口**输出**：

-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
