# Change Space

菜单路径： **Operator > Math > Geometry > Change Space**

 **Change Space**运算符可以将输入的空间从局部空间更改为全局空间，或者从全局空间更改为局部空间。

可以使用该选项将系统中粒子的位置从局部空间转化为其对应的世界空间位置。

## 运算符设置

| **Setting**      | **Type** | **描述**|
| ---------------- | -------- | ------------------------------------------------------------ |
| **Target Space** | enum     |指定要将输入更改为的空间。选项包括：<br/>•**本地的**：将输入更改为局部空间。<br/>•**世界**：将输入更改为世界空间。|

## 运算符属性

| **Input** | **Type**                                | **描述**|
| --------- | --------------------------------------- | --------------------------------------------- |
| **X**     | [Configurable](#operator-configuration) |此运算符的输入将更改的空间。|

| **Output** | **类型**| **Description**                   |
| ---------- | --------------------------------------- | --------------------------------- |
| **-**      | [可配置](#operator-configuration)| The input in its converted space. |

## 运算符配置

要查看该运算符的配置，请单击**齿轮**运算符标题中的图标。使用下拉列表选择输入类型。有关这些属性支持的类型的列表，请参见[可用类型](#available-types)。



### 可用类型

你可以将以下类型用于**输入值**和端口**输出**：

-  **方向**
-  **位置**
-  **向量**
