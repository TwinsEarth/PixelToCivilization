# Rectangular to Polar

菜单路径： **Operator >  Math > Coordinates**

运算符**Rectangular to Polar**执行矩形XY空间到极坐标（theta/距离）空间之间的2D坐标转换。

## 运算符属性

| **Input**      | **Type** | **描述**|
| -------------- | -------- | ------------------------ |
| **Coordinate** | Vector2  |输入2D坐标。|

| **Output**   | **Type** | **描述**|
| ------------ | -------- | ---------------------------------- |
| **theta**    | float    |输出角度（以弧度表示）。|
| **distance** | float    |到原点的输出距离。|
