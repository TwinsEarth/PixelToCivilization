# Reciprocal (1/x)

菜单路径： **Operator > Math > Arithmetic > Reciprocal (1/x)**

 **Reciprocal**运算符计算1除以输入值的结果。例如，输入（0.2，2， - 5）输出（5，0.5， - 0.2）。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。**Reciprocal**运算符将始终返回与其输入类型相同的值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |从1 <br/>**类型**中减去输入的值。更改以匹配的**X**类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。使用下拉列表选择**X**端口类型。有关此属性支持的类型的列表，请参见[可用类型](#available-types)。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
