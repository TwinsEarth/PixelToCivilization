# Exp

菜单路径： **Operator > Math > Exp**

 **Exp**运算符将基数提高到指定的幂。它支持三个公共基础：Exp、Exp2 <sub></sub>和Exp10 <sub></sub>。

Exp将该数字**E**（近似等于2.7 18281828459的数学常数）提升到指定的幂。带底**E**的指数函数在数学和科学中经常使用。

EXP2 <sub></sub>将数字**2**提高到指定的幂。例如，exp2 (3）等于 *2\*2\ *2*，即8。

EXP10 <sub></sub>将数字**10**提高到指定的幂。例如，EXP10 (3）等于 *10\*10\ *10*，即1000。

## 运算符设置

| **Property** | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------------------------ |
| **Base**     | Enum     |指定操作符要使用的基础。这些选项包括：<br/>•**基数2**：将数字**2**乘以在中**X**指定的幂。<br/>•**基数10**：将数字**10**乘以在中**X**指定的幂。<br/>•**碱基E**：将**E**（2.7 18..）乘以中**X**指定的幂次。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。使用下拉列表选择**X**端口类型。有关此属性支持的类型的列表，请参见[可用类型](#available-types)。

### 可用类型

你可以为**输入**端口使用以下类型：
-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Position**
