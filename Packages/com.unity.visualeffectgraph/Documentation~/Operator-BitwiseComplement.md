# Complement (Bitwise)

菜单路径：**Operator > Bitwise > Complement**

**Complement** 对二进制形式数字的每一位应用按位逻辑 *NOT* 运算。这将反转每一位，意味着 0 位变为 1，1 位变为 0。例如：

+   二进制输入 01011101 的输出为 10100010。
    
+   十六进制输入 0xF0F0F0F0 的输出为 0x0F0F0F0F。
    

## 运算符属性

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **X** | uint | 此运算符要对其执行按位逻辑 *NOT* 运算的值。 |

| **输出** | **类型** | **描述** |
| --- | --- | --- |
| **o** | uint | 对输入值执行按位 *NOT* 运算的结果。 |
