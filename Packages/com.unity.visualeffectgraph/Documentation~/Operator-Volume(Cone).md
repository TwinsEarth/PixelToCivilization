# Volume (Cone)

菜单路径： **Operator > Math > Geometry > Volume (Cone)**

**Volume (Cone)** 运算符计算圆锥体的体积。这等于，**1/3 π h(R<sup>2</sup> + R r + r<sup>2</sup>)**其中**H**是圆锥的高度，**R**是底面的半径，**R**是帽的半径。

##  属性

| **Input** | **Type** | **描述**|
| --------- | -------- | ------------------------------------------------ |
| **Cone**  | Cone     |此运算符计算体积的圆锥体。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ----------------------- |
| **Volume** | float    |圆锥的体积。|
