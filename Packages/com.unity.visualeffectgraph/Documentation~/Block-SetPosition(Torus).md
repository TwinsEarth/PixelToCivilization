# 设置位置（形状：圆环）

菜单路径： **Position > Set Position (Shape : Torus)**

 **设置位置（形状：圆环）**块根据输入[ArcTorus](Type-ArcTorus.md)计算位置，并根据组合将结果存储在中[位置属性](Reference-Attributes.md)。

圆环体形状将圆弧属性添加到圆环体，以确定其圆弧角度（以弧度为单位）。将圆弧值设置为PI将创建半圆环体。

该块可以从弧面**表面**、**音量**或**厚表面**计算位置，其中厚度可以相对于形状的大小或绝对值。


此块还根据形状上的计算位置计算方向矢量，并根据合成将其存储到[方向属性](Reference-Attributes.md)。该方向等于从环面圆心到计算位置的归一化矢量。

注意：[来自方向和速度的速度](Block-VelocityFromDirectionAndSpeed.md)块可以处理方向属性。

## 块设置

| **Setting**               | **Type** | **描述**|
| ------------------------- | -------- | ------------------------------------------------------------ |
| **Position Mode**         | Enum     |指定此块如何使用形状来计算位置。选项包括：<br/>•**表面**：仅计算形状表面上的位置。<br/>•**音量**：计算整个形状体积内的位置。<br/>•**绝对厚度**：计算给定绝对厚度的厚表面上的位置。<br/>。**厚度相对**将计算给定形状大小百分比的厚表面上的一个位置。|
| **Spawn Mode**            | Enum     |此块用于沿形状的圆弧分布粒子的方法。<br/>•**随机的**：计算每粒子随机进度（0..1）在弧线上。<br/>•**习俗**：允许你在**电弧序列器**属性中指定进度。|
| **Composition Position**  | Enum     | **（检验员）**指定此块构成位置属性的方式。选项包括：<br/>•**组**：用新值覆盖位置属性。<br/>•**加**：将新值与位置属性值相加。<br/>•**相乘**：将位置属性值乘以新值。<br/>•**混合**：在位置属性值和新值之间进行插值。可以指定介于0和1之间的混合因子。|
| **Composition Direction** | Enum     | **（检验员）**指定此块构成方向属性的方式。选项包括：<br/>•**组**：用新值覆盖位置属性。<br/>•**加**：将新值与位置属性值相加。<br/>•**相乘**：将位置属性值乘以新值。<br/>•**混合**：在位置属性值和新值之间进行插值。可以指定介于0和1之间的混合因子。|

## 块属性

| **Input**           | **Type**                     | **描述**|
| ------------------- | ---------------------------- | ------------------------------------------------------------ |
| **ArcTorus**        | [ArcTorus](Type-ArcTorus.md) |确定要计算位置的形状的弧面。|
| **Thickness**       | Float                        |用于位置计算<br/>的形状曲面的厚度。此属性仅在设置**位置模式**为**厚度相对**或**绝对厚度**时显示。|
| **Arc Sequencer**   | Float                        |圆弧中用于繁殖粒子的位置。<br/>此属性仅在设置**产卵模式**为**习俗**时显示。|
| **Blend Position**  | Float                        |当前位置属性值与新计算的位置值之间的混合百分比。<br/>此属性仅在设定**构图位置**为**混合**时显示。|
| **Blend Direction** | Float                        |当前方向属性值与新计算的方向值之间的混合百分比。<br/>此属性仅在设定**构图方向**为**混合**时显示。|
