# Volume (Sphere)

菜单路径： **Operator > Math > Geometry > Volume (Sphere)**

 **Volume (Sphere)**操作符计算球体的体积。这等于**4/3 π r<sup>2</sup> h**。

## 运算符属性

| **Input**  | **Type** | **描述**|
| ---------- | -------- | -------------------------------------------------- |
| **Sphere** | Sphere   |此操作符计算的球体体积。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------ |
| **Volume** | Float    |球体的计算体积。|
