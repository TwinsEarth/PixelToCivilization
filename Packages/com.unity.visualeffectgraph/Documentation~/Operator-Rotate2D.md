# Rotate 2D

菜单路径： **Operator > Math > Vector**

运算符**Rotate 2D**围绕给定中心执行输入点和给定角度的2D旋转。

## 运算符属性

| **Input**           | **Type** | **描述**|
| ------------------- | -------- | ----------------------------------------- |
| **Position**        | Vector2  |要旋转的点。|
| **Rotation Center** | Vector2  |要围绕旋转**位置**的点。|
| **Angle**           | float    |要使用的旋转角度，以弧度为单位。|

| **Output**   | **Type** | **描述**|
| ------------ | -------- | --------------------- |
| **Position** | Vector2  |旋转位置。|
