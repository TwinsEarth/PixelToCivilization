# ArcCircle

由角度和 [Circle](Type-Circle.md) 定义的圆形的实心圆弧。如果您只想使用圆形的一部分，例如半圆，这将非常有用。



## 属性

| **属性** | **描述**                                        |
| ------------ | ------------------------------------------------------ |
| **Circle**   | 要取其一部分的 [Circle](Type-Circle.md) 。 |
| **Arc**      | 圆形段的角度（以弧度为单位）。          |
