# Area (Circle)

菜单路径： **Operator > Math > Geometry > Area (Circle)**

 **Area (Circle)**运算符计算圆的面积。这等于**π r<sup>2</sup>**。

## 运算符属性

| **Input**  | **Type** | **描述**|
| ---------- | -------- | ------------------------------------------------ |
| **Circle** | Circle   |此运算符计算圆的面积。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------------- |
| **Area**   | float    |基于其半径的圆的面积。|
