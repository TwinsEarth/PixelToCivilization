# Divide

菜单路径： **Operator > Math > Arithmetic > Divide**

 **Divide**运算符按顺序将第一个输入除以所有其他输入。例如，输入值（1，2）/ (3，4，5）输出（0.33，0.5，0.2）。输入值（1，2)/3输出（0.33，0.66）。

此操作符接受多种类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。此运算符将任何缺少的输入解释为的值**1**，并始终返回其输入的最大向量类型的值。它将float、int和uint等标量值视为最大的向量，并在所有向量的字段中使用该值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **Input** | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |第一个输入除以所有其他输入。 <br/>**类型**更改以匹配运算符输入的最大向量类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。你将看到可以重新排序、重命名、更改类型或删除的输入列表。输入的最小数量是两个，没有最大值。使用“+”按钮添加元素。如果有三个或更多输入，你可以使用“ -”按钮删除选定的输入。使用输入左侧的手柄拖动并重新排序。

该**Divide**操作符还有一个空输入，你可以链接该输入以添加新输入。



### 可用类型

你可以为**输入**端口使用以下类型：


-  **float**
-  **int**
-  **uint**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
