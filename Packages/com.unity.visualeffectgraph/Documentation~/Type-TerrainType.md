# TerrainType

由一组边界、高度贴图和高度定义的 Unity 地形。

## 属性

| **属性**   | **描述**                                              |
| -------------- | ------------------------------------------------------------ |
| **Bounds**     | 地形的边界。这是一个 [AABox](Type-AABox.md)。 |
| **Height Map** | 地形的高度贴图。                               |
| **Height**     | 地形的高度。这是地形可以具有的最高海拔。 |
