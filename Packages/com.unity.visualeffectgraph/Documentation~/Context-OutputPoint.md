# Output Particle Point
菜单路径 : **Context > Output Particle Point**

**Output Particle Point** 上下文使用点来渲染粒子系统。无论粒子与摄像机的距离有多远，以及每个粒子的大小和比例属性如何，它始终以单个像素的形式绘制点。

此输出不支持纹理或 [Shader Graph](https://docs.unity.cn/cn/Packages-cn/com.unity.shadergraph@latest)。

有关此上下文与所有其他上下文共享的通用输出设置的信息，请参阅 [全局输出设置和属性](Context-OutputSharedSettings.md)。
