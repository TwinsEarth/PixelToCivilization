# Cone

由高度、上半径和下半径定义的 3D 锥体。

## 属性

| **属性**    | **描述**                                              |
| --------------- | ------------------------------------------------------------ |
| **Transform**   | 圆锥体的变换，枢轴位于底帽的中心。 |
| **Base Radius** | 圆锥体底部的半径。                         |
| **Top Radius**  | T圆锥体尖端的半径。                          |
| **Height**      | 锥体的高度。                                      |
