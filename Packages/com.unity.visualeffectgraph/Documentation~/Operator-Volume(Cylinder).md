# Volume (Cylinder)

菜单路径： **Operator > Math > Geometry > Volume (Cylinder)**

**Volume (Cylinder)** 操作符计算圆柱体的体积。这等于，**π r<sup>2</sup> h**其中**R**是半径，**H**是圆柱的高度。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ---------------------------------------------------- |
| **Cylinder** | Cylinder |此运算符计算其体积的圆柱体。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | --------------------------- |
| **volume** | float    |圆柱体的体积。|
