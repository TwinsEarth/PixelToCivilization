# Rotate 3D

菜单路径： **Operator > Math > Vector**

运算符**Rotate 3D**围绕给定的中心和轴执行输入点和给定角度的3D旋转。

## 运算符属性

| **Input**           | **Type**  | **描述**|
| ------------------- | --------- | ----------------------------------------- |
| **Position**        | Position  |要旋转的点。|
| **Rotation Center** | Position  |要围绕旋转**位置**的点。|
| **Rotation Axis**   | Direction |要围绕其旋转**位置**的轴。|
| **Angle**           | float     |要使用的旋转角度，以弧度为单位。|

| **Output**   | **Type** | **描述**|
| ------------ | -------- | --------------------- |
| **Position** | Position |旋转位置。|
