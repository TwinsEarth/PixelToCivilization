# Transpose (Matrix)

菜单路径： **Operator > Math > Geometry > Transpose (Matrix)**

 **Transpose (Matrix)**运算符沿矩阵的对角线翻转矩阵，交换矩阵的列值和行值。这与[矩阵4x4转置](https://docs.unity3d.com/ScriptReference/Matrix4x4-transpose.html)操作相同。

## 运算符属性

| **Input**  | **Type** | **描述**|
| ---------- | -------- | ------------------------------------ |
| **Matrix** | Matrix   |这个算子转置的矩阵。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------ |
| **Matrix** | Matrix   |Transpose (Matrix)的结果。|
