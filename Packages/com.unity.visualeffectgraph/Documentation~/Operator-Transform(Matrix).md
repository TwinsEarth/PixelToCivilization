# Transform (Matrix)

菜单路径： **Operator > Math > Geometry > Transform (Matrix)**

 **Transform (Matrix)** 操作符将变换应用于矩阵以修改其位置、旋转或缩放。

## 运算符属性

| **Input**     | **Type**  | **描述**|
| ------------- | --------- | -------------------------------------------------- |
| **Transform** | Transform |此运算符的变换应用于矩阵。|
| **Matrix**    | Matrix    |此运算符变换的矩阵。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------- |
| **Matrix** | Matrix   |变换矩阵的结果。|
