# Not（逻辑）

菜单路径：**Operator > Logic > Not**

**Not** 运算符接受单个输入并输出逻辑 *not* 运算的结果。如果 A 为`false`，则 **Not** A 结果为`true`。此运算符等效于 C#`!`运算符。

## 运算符属性

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **A** | bool | 此运算符评估的值。如果此值为`false`，则 **o** 为`true`。 |

| **输出** | **类型** | **描述** |
| --- | --- | --- |
| **o** | bool | 如果 **A** 为`true`，则此值为`false`。否则，如果 **A** 为`false`，此值为`true`。 |
