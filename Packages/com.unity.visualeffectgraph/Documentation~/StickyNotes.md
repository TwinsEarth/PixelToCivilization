# Sticky Notes 便笺

Sticky Notes 是图形视图中可以写入的对象。它们是相当于代码中注释的图形视图，由标题和正文组成。您可以在图表中创建任意数量的数据，并将其用于各种目的，例如：

- 描述图表的某个部分的工作原理。
- 为自己或在 Unity 项目中协作的其他人留下注释。
- 作为包含稍后要完成的任务的待办事项列表。

## 使用 Sticky Notes

要创建便笺，请右键单击图表视图中的空白区域，然后在上下文菜单中单击 **Create Sticky note**。您现在可以自定义新便笺并将其添加到新便笺中。您可以写入两个文本区域：

- **标题**：便笺条顶部的文本区域是标题。在这里，您可以简明扼要地描述 Sticky Note 在其正文文本区域中包含的内容。例如，这可能是 Sticky Note 描述的图表部分的名称。
- **正文**：标题区域下方的较大文本区域是正文。您可以在此处写下注释的完整内容。

### 控制

本节介绍如何编辑文本、移动便笺和调整便笺大小以及执行其他操作。

#### 编辑文本

要编辑便笺上的文本，请双击文本区域。这也会选择区域中的所有文本，因此请务必在编辑文本之前移动文本光标。

#### 移动和调整大小

您可以将 Sticky Notes （便笺） 移动到图表上的任意位置。有关如何执行此操作的信息，请参阅[操作图形元素](VisualEffectGraphWindow.md#moving-elements)。

您还可以调整便笺的大小。您可以手动调整便笺的大小，或者便笺可以自动调整自身大小以适应其内容。有关如何使便笺自行调整大小的信息，请参阅[Context menu](#context-menu)中的 **Fit To Text** 选项。有关如何手动调整附注大小的信息，请参阅[操作图形元素](VisualEffectGraphWindow.md#moving-elements)。

#### 复制

您还可以剪切、复制、粘贴和复制便笺。有关如何执行这些操作的信息，请参阅 [复制元素](VisualEffectGraphWindow.md#copy-cut-and-paste-and-duplicate-elements).

#### Context menu

要打开 Sticky Note 的上下文菜单，请右键单击 Sticky Note 上的任意位置。上下文菜单中的选项如下。

| **选项**                 | **描述**                                              |
| -------------------------- | ------------------------------------------------------------ |
| **Dark Theme/Light Theme** | 在浅色主题和深色主题之间切换便笺条的颜色主题。 |
| **Text Size**              | 将文本区域中的字体大小调整为以下值：  |
| Small                      | 标题: 20<br/>正文: 11                                       |
| Medium                     | 标题: 40<br/>正文: 24                                       |
| Large                      | 标题: 60<br/>正文: 36                                       |
| Huge                       | 标题: 80<br/>正文: 56                                       |
| **Fit To Text**            | 调整便笺的大小，使其与文本区域精确匹配。<br/>**注意**: 如果标题分布在多行上，则会将便笺大小水平调整为标题文本适合单行的最小大小。 |
