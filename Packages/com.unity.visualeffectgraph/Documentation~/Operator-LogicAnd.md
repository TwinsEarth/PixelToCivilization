# And（逻辑）

菜单路径：**Operator > Logic > And**

**And** 运算符接受两个输入并输出两者的逻辑 *And* 运算结果。如果 A 和 B 均为 `true`，则 A **And** B 结果为 `true`。此运算符等效于 C# `&&` 运算符。

## 运算符属性

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **A** | bool | 左操作数。如果此值和 **B** 均为`true`，则 **o** 为`true`。 |
| **B** | bool | 右操作数。如果此值和 **A** 均为`true`，则 **o** 为`true`。 |

| **输出** | **类型** | **描述** |
| --- | --- | --- |
| **o** | bool | 如果 **A** 和 **B** 均为`true`，此值为`true`。否则，如果 **A** 或 **B** 有任何一个为`false`，此值为`false`。 |
