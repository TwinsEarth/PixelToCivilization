# Negate (-x)

菜单路径： **Operator > Math > Arithmetic > Negate (-x)**

 **否定**运算符将输入值乘以 - 1. 例如，输入 - (3，4， - 5）输出（ - 3， - 4，5）。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。**否定**运算符始终输出与其输入类型相同的值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |输入的相反值。 <br/>**类型**更改以匹配运算符输入的类型。|

## 运算符配置

要查看**否定**运算符的配置，请单击**齿轮**运算符标题中的图标。中[可用类型](#available-types)选择输入的类型。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **int**
-  **uint**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
