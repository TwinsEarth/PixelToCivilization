# Epsilon(Ɛ)

菜单路径： **Operator > Math > Constants > Epsilon (Ɛ)**

**Epsilon(Ɛ)** 运算符返回一个极小的值。这对于比较很有用，因为它可以帮助避免浮点数的潜在精度问题。

## 运算符属性

| **Output** | **Type** | **描述**|
| ---------- | -------- | --------------------------------------------------------- |
| **Ɛ**      | float    |ε值。这等于 `1e-05` 或 `0.00001`。|
