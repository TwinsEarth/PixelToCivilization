# Pi（π）

菜单路径： **Operator > Math > Constants > Pi (π)**

 **Pi（π）**运算符返回数字Pi（π）。这是圆的周长与直径之比。

## 运算符属性

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------------------------------------------ |
| **π**      | float    |圆周率的值。此值与[Mathf.PI](https://docs.unity3d.com/ScriptReference/Mathf.PI.html)相同。|
| **2π**     | float    |2*Pi的结果。|
| **π/2**    | float    |Pi/2的结果。|
| **π/3**    | float    |PI/3的结果。|
