# 版本 13 / Unity 2022.1 的新增功能

本页概述了 Visual Effect Graph 版本 13 中嵌入的新功能、改进和已解决的问题，嵌入在 Unity 2022.1 中。

## 新功能

以下是 Unity 添加到 Unity 2022.1 中嵌入的 Visual Effect Graph 版本 13 的功能列表。每个条目都包含功能摘要和指向任何相关文档的链接。

### 排序模式

现在，您可以根据粒子与摄像机的距离、摄像机深度、粒子的年龄或任何自定义输入对粒子进行排序。

![img](images/VFX-WhatsNew13-3.png)

### 新建工具栏

VFX 工具栏已简化，并包含用于快速访问文档和示例的新选项。

![img](images/VFX-WhatsNew13-2.png)

### 多个 VFX 窗口

现在，您可以同时打开多个 VFX 图形，并将一个图形复制并粘贴到另一个图形。

![img](images/VFX-WhatsNew13-1.png)

## 修复问题

有关 Unity 2022.1 中嵌入的 Visual Effect Graph 版本 13 中已解决的问题的信息，请参阅[更改日志](../changelog/CHANGELOG.html)。
