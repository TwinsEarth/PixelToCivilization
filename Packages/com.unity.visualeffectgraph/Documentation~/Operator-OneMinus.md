# One Minus (1-x)

菜单路径： **Operator > Math > Arithmetic > One Minus (1-x)**

运算符计算**1**的**One Minus**值减去输入值。例如，输入0.2输出0.8，输入（0.3，0.4， - 5）输出（0.7，0.6，6）。

此操作符接受许多不同类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。此运算符始终返回与输入类型相同的值。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **X**     | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |从1中减去的输入值。 <br/>**类型**更改以匹配运算符的输入。|

## 运算符配置

要查看**One Minus**运算符的配置，请单击**齿轮**运算符标题中的图标。可以从中选择一种类型[可用类型](#available-types)。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **float**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
