# Or (Bitwise)

菜单路径：**Operator > Bitwise > Or**

**Or** 运算符接受两个输入并输出两者的按位 *or* 运算结果。对于 **A** 和 **B** 中的每一位，如果其中任何一个是 **1**，则输出为 **1**。否则，输出为 **0**。

例如，如果 **A** 输入为 26，**B** 输入为 19，则输出为 27。这是因为，在二进制中，26 表示为 11010，29 表示为 10011，因此结果为 11011，即 27 的二进制表示形式。

## 运算符属性

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **A** | uint | 左操作数。 |
| **B** | uint | 右操作数。 |

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **o** | uint | **A** 与 **B** 之间的按位 *or* 运算的结果。 |
