# Spherical to Rectangular

菜单路径： **Operator >  Math> Coordinates**

操作者**Spherical to Rectangular**执行球形（theta/phi/distance）空间到矩形XYZ空间之间的3D坐标转换。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------ |
| **Theta**    | float    |输入球体Theta角度（以度为单位）。|
| **Phi**      | float    |输入球体phi角度（以度为单位）。|
| **Distance** | float    |输入距离。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | -------------------------- |
| **coord**  | Vector3  |输出XYZ坐标。|
