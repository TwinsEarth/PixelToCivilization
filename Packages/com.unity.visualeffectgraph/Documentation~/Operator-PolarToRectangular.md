# Polar to Rectangular

菜单路径： **Operator >  Math > Coordinates**

运算符**Polar to Rectangular**执行极坐标（theta/距离）空间到矩形XY空间之间的2D坐标转换。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ----------------------------- |
| **Angle**    | float    |输入角度（以度为单位）。|
| **Distance** | float    |输入距离。|

| **Output** | **Type** | **描述**|
| ---------- | -------- | ------------------------- |
| **coord**  | Vector2  |输出XY坐标。|
