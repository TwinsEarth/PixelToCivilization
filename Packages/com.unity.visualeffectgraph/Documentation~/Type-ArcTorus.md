# ArcTorus

由角度和 3D [Torus](Type-Torus.md) 定义的圆环体的实心圆弧。如果您只想使用圆环体的一部分，这很有用。

## 属性

| **属性** | **描述**                                       |
| ------------ | ----------------------------------------------------- |
| **Torus**    | 从  [Torus](Type-Torus.md) 中获取字段。 |
| **Arc**      | 圆环段的角度（以弧度为单位）。          |
