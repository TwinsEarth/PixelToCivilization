# Add

菜单路径： **Operator > Math > Arithmetic > Add**

 **加**运算符计算其所有输入的总和。例如，输入值（1，2） + (3，4，5）输出（4，6，5）。或者，输入值（1，2) +3输出（4，5）。

此操作符接受各种类型的输入值。有关此运算符可以使用的类型的列表，请参见[可用类型](#available-types)。此运算符将始终返回其输入的最大向量类型的值。

此运算符将缺失值解释为零。它将诸如float、int和unit之类的标量值解释为与最大向量输入一样大，并且标量值占据向量的每个成员。

此操作符还有一个空输入，你可以链接该输入以添加新输入。

## 运算符属性

| **Input** | **类型**| **Description**                    |
| --------- | --------------------------------------- | ---------------------------------- |
| **Input** | [可配置](#operator-configuration)| The value this Operator evaluates. |

| **Output** | **Type**  | **描述**|
| ---------- | --------- | ------------------------------------------------------------ |
| **Out**    | Dependent |所有输入的总和。 <br/>**类型**更改以匹配运算符输入的最大向量类型。|

## 运算符配置

要查看运算符的配置，请单击**齿轮**运算符标题中的图标。你将看到可以重新排序、重命名、更改类型或删除的输入列表。输入的最小数量是两个，没有最大值。使用“+”按钮添加元素。如果有三个或更多输入，你可以使用“ -”按钮删除选定的输入。使用输入左侧的手柄拖动并重新排序。



### 可用类型

你可以为**输入**端口使用以下类型：

-  **int**
-  **uint**
-  **Vector**
-  **Vector2**
-  **Vector3**
-  **Vector4**
-  **Position**
-  **Direction**
