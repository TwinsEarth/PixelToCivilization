# Torus

在 XY 平面上定向的 3D 圆环，由位置、大半径（圆环半径）和小半径（圆环厚度）定义。

## 属性

| **属性**     | **描述**                                              |
| ---------------- | ------------------------------------------------------------ |
| **Transform**    | 圆环体的位置。                                  |
| **Major Radius** | 圆环体的半径。它是从圆环体中心到管道中心的距离。 |
| **Minor Radius** | 管道的半径。                                     |
