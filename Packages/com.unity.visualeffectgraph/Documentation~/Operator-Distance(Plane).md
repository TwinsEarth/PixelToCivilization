# Distance (Plane)

菜单路径： **Operator > Math > Geometry > Distance (Plane)**

 **Distance (Plane)**操作符操作符取一个平面和一个位置，并计算：

- 平面上距离位置最近的点。
- 最近点与位置之间的距离。

## 运算符属性

| **Input**    | **Type** | **描述**|
| ------------ | -------- | ------------------------------------------------------------ |
| **Plane**    | Plane    |此运算符计算的平面。此运算符返回的点（**最接近位置**）是此平面**位置**上最接近的点。|
| **Position** | Position |此运算符计算的平面。此运算符返回的点（**最接近位置**）是距离此位置最近的点**飞机**。|

| **Output**          | **Type** | **描述**|
| ------------------- | -------- | ------------------------------------------------------------ |
| **closestPosition** | Position |上 **飞机****位置**的最近点的位置。|
| **distance**        | float    |从**位置**到**最接近位置**的距离。如果**位置**高于**飞机**，则该值为正。如果**位置**低于**飞机**，则该值为负值。|
