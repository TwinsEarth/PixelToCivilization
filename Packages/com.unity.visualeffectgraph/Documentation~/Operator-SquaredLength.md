# Squared Length

菜单路径：**Operator > Math > Vector**

**Squared Length** [统一运算符](uniform-operators.md)计算 1D、2D 或 3D 矢量的长度的平方。

## 运算符属性

| **输入** | **类型** | **描述** |
| --- | --- | --- |
| **X** | [Configurable](#operator-configuration) | 要计算平方长度的矢量。 |

| **输出** | **类型** | **描述** |
| --- | --- | --- |
| **输出** | float | 输入矢量的平方长度。 |

## 运算符配置

要查看此[统一运算符](uniform-operators.md)的配置，请单击节点标题中的**齿轮**图标。您可以在此处配置此运算符使用的数据类型。

### 可用类型

您可以将以下类型用于**输入值**和端口：

+   **Position**
+   **Vector**
+   **Vector3**
+   **Vector2**
+   **Float**
